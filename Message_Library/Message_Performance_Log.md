## HOW TO USE THIS FILE
This file tracks the performance of every message
variant sent through the system. Claude reads this
file when running the Message Drafting Agent to
prioritize variants with proven response rates.
Update this file every Friday during your
5-minute system review. Log every send that
produced a response or a quote request.
Log every send that produced silence.
After 30 days of data Claude can identify
which variants, channels, and angles are
producing results and which are not.
---
## PROMOTION AND RETIREMENT RULES
PROMOTION TO DEFAULT
Any message variant that produces a 30% or higher
response rate across 10 or more sends for a
specific contractor type gets promoted to default
for that type. Mark promoted variants with
[DEFAULT] tag.
RETIREMENT
Any message variant that produces under 15%
response rate across 10 or more sends gets
retired. Move retired variants to the
RETIRED VARIANTS section at the bottom
of this file. Do not delete them —
they become negative examples that help
Claude avoid repeating unsuccessful approaches.
THREE-REPETITION RULE
Any variant that produces a measurable positive
outcome three consecutive times becomes a
permanent default regardless of total send count.
